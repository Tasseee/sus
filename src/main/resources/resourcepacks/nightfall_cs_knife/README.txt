Nightfall CS-style Knife Resource Pack

This is an optional cosmetic resource pack. It replaces the vanilla iron sword model
with a custom low-poly, CS-inspired 3D knife model and texture.

Install:
1. Copy this folder (or a ZIP of its contents) into .minecraft/resourcepacks.
2. Enable it in Options > Resource Packs.
3. Hold an iron sword to see the replacement.

Notes:
- This pack replaces the iron sword globally while enabled; it does not add a new
  server-side item and does not change gameplay or hitboxes.
- If Minecraft reports an incompatible pack format, update pack_format in pack.mcmeta
  to the resource-pack format required by your exact Minecraft 1.21.11 client.
- This is a custom generic knife design, not a copy of a specific copyrighted CS skin.
